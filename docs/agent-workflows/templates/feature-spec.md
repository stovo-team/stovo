# Feature contract template

Status: draft. Follow [approval policy](../approvals.md).

- User problem and concrete before/after behavior.
- Scope and exclusions; affected existing routes/callers.
- Existing helpers, components, platform capabilities and dependencies considered.
- Selected approach and alternatives; interfaces, security/accessibility and data-loss constraints.
- Stable acceptance IDs with observable expected results.
- Linked test plan and implementation sequence when needed.
- Unresolved decisions and blockers.
- Human decision: actual source, actor, reviewed artifact digests and authorized action scopes. Leave pending until a human decision exists.
