# Dependency decision template

- Task and capability needed; existing caller/component search.
- Platform/installed choices and relevant external alternatives; official/upstream references.
- Exact versions, licenses, maintenance and advisories, with date and uncertainty.
- Compatibility, transitive dependencies, bundle/runtime and maintenance cost.
- Chosen approach, rejected relevant alternatives and lockfile impact.
- Verification and actual authorization when an external action is needed.
