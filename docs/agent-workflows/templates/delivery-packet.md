# Delivery packet template

- Task, approved contract/digest and exact source/dirty-patch identity.
- Concrete problem and resulting observable behavior.
- Scope; existing issue/spec links; changed paths.
- Actual commands, outcomes, duration, acceptance IDs and artifact hashes.
- Independent QA source, findings and resolution evidence.
- Visual before/after artifacts and environment, or a justified nonvisual classification.
- Risks, limitations and short manual review steps.
- Applicable actual publication authorization; merge/deployment remain separately scoped.

Run the readiness validator before rendering the PR body. A useful description does not waive missing required checks. Local approval/QA records document evidence but do not authenticate their own authors.
