# Reusable code proposal template

- Candidate or no-candidate outcome and reason.
- Concrete second consumer and useful stable API.
- Product-specific coupling and removal cost.
- Tests, provenance, applicable licenses and attribution.
- Extraction effort, ownership and ongoing maintenance.
- Proposed repository/package and authorization required before any external mutation.
