# Acceptance test plan template

Status: draft. Review with the spec under [approval policy](../approvals.md).

| Acceptance ID | Scenario/input | Expected result | Proof layer | Command/check ID | Evidence |
| --- | --- | --- | --- | --- | --- |
| AC-01 | Named user action | Observable behavior | Unit/component/integration/E2E/visual | Exact command or named scenario | Result, revision and artifact |

Cover meaningful edge, error, permission, keyboard and responsive states. State synthetic fixtures and isolation prerequisites. Record mandatory versus optional checks and honest blocked/not-applicable reasons. For visual work name viewport, theme, locale, before/after state and reference-review requirement. Keep model evals distinct from product tests.
