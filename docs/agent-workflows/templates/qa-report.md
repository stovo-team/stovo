# Independent QA report template

- Task, approved contract digest and exact reviewed source/patch digest.
- Reviewer identity and independent-context source.
- Acceptance coverage: each required criterion, executed check and actual outcome.
- Findings: severity, concrete trigger, user impact, exact path/line, reproduction and sanitized evidence.
- Missing/error/responsive/keyboard/permission states investigated.
- Required checks unavailable and precise unblock conditions.
- Resolution: reported, fixed with unchanged regression RED→GREEN, or explicit human decision. Preserve unresolved important findings as blockers.
- Product sources and expected assertions left unchanged by reviewer.
