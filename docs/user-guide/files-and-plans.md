# Files and plans

Stovo brings shared files and plans into the workspace. What you can open, upload or create depends on your account's permissions and the configuration of your instance.

## Find or upload a file

1. Open **Files** in the main navigation.
2. Select **All chats** or a source chat, then use **Search files** or filters such as **Documents**, **Photos**, **Canvases** and **Checklists**.
3. Select a file to inspect the available preview and actions. Depending on the item and your access, actions include **Download**, **Favorite**, **Open in chat** and **Delete**.
4. To add a file, use **Upload files** and select the file on your device. Files can also be attached from a chat's composer.

A missing file may belong to another chat, be filtered out, or be inaccessible to your account. Check the source and filter first; ask the relevant chat or workspace administrator about access. A file preview may be unavailable on a particular device; the interface can offer an action to open or download it instead.

## View or create a plan

Open **Plans** in the main navigation. Use **Today**, **3 days**, **Week** or **Month** to change the displayed range, and **Find a plan** to search. Select a plan to see its details and available attendance response.

To add a plan, select **Create plan** (plus), provide its **Title**, **Starts** and **Ends**, and choose **Create plan**. Other fields include location and description. The create action may be disabled for your role; ask a workspace administrator if you need access.
