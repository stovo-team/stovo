# Repository instructions

## Commit messages

Use the established bracketed type prefix and a concise, sentence-case summary:

```text
[Type] Summary of the change
```

Use one of: `Fix`, `Feat`, `Docs`, `Refactor`, `Test`, `Build`, `CI`, or `Chore`.

Examples:

```text
[Fix] Harden Caddy HTTPS recovery
[Docs] Specify idle audio progress
```
